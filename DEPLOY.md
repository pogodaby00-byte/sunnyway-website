# Sunnyway — запуск на Render

## Что входит
- Многостраничный сайт и адаптивные стили.
- Node.js сервер, который отдаёт сайт и API `/api/tours`, `/api/health`.
- Адаптер для разрешённых JSON-выгрузок туроператоров.

## Быстрый запуск на Render
1. Загрузите содержимое этой папки в новый GitHub-репозиторий (не загружайте реальные пароли или токены).
2. В Render выберите **New → Web Service** и подключите репозиторий.
3. Runtime: Node; Build command: `npm install` (зависимостей нет, но команда допустима); Start command: `npm start`.
4. В настройках сервиса добавьте переменные окружения при наличии официальных JSON-выгрузок:
   - `CORAL_FEED_URL` — HTTPS URL JSON-выгрузки Coral, если оператор её предоставил.
   - `MIROMAX_FEED_URL` — HTTPS URL JSON-выгрузки MIROMAX, если оператор её предоставил.
   - `OTHER_FEED_URLS` — дополнительные HTTPS JSON URL через запятую.
   - `FEED_CACHE_SECONDS` — необязательно, например `300`.
5. После публикации откройте `/api/health`, чтобы увидеть состояние источников, и `/api/tours` — каталог.

## Важно
- Сервер принимает только HTTPS JSON-выгрузки, доступ к которым вам разрешён. Это не универсальный парсер HTML-сайтов туроператоров.
- Если у поставщика XML, CSV или иной API, нужен адаптер под его официальную схему.
- Без настроенных выгрузок API вернёт пустой каталог, а не выдуманные цены.
- Заявка на текущей статической форме использует WhatsApp. Для сохранения заявок в базе и уведомлений нужно дополнительно подключить базу данных и почтовый/Telegram-сервис.
- Никогда не храните секретные ключи в коде, GitHub или браузерном JavaScript.
